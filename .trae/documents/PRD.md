# TOC清晰思考技能应用 - 产品需求文档

## 1. 产品概述

**项目名称**: TOC清晰思考技能助手

**一句话描述**: 一个基于制约理论(TOC)五步思考流程的交互式技能引导应用，帮助用户将复杂问题可视化、系统化地找到双赢解决方案。

**目标用户**:
- 面临复杂决策困境的职场人士
- 需要系统性解决问题的人士
- 对TOC思考法感兴趣的学习者

**核心价值**:
- 将抽象的TOC思考流程具象化、可视化
- 引导式交互降低学习门槛
- 实时构建冲突图、现状图等思维工具

---

## 2. 核心功能

### 2.1 五大思考步骤引导

| 步骤 | 名称 | 核心功能 |
|------|------|----------|
| 第一步 | 冲突图构建 | 引导用户定义两难困境，填充D/D'/B/C/A实体 |
| 第二步 | 现状图构建 | 收集不良效应，构建因果链，发现恶性循环 |
| 第三步 | 双赢方案开发 | 提供4种破解方法，选择并注入激发方案 |
| 第四步 | 方案完善 | 消除负面分支，补充完整因果链 |
| 第五步 | 说服与实施 | 四象限分析，制定行动清单 |

### 2.2 可视化图表系统

- **冲突图(Evaporating Cloud)**: 经典TOC冲突图，支持D/D'/B/C/A五框动态连线
- **现状图(Current Reality Tree)**: 不良效应因果链图，支持拖拽排序和连线
- **因果箭头**: SVG绘制的贝塞尔曲线箭头，带动画效果
- **四象限图**: 改变四象限矩阵（金子/鳄鱼/美人鱼/拐杖）

### 2.3 交互功能

- 步骤进度导航（可前进/后退）
- 引导式提问卡片（逐步揭示）
- 方案评估与选择机制
- 本地存储会话数据
- 导出思考结果为图片

---

## 3. 页面结构

### 3.1 页面列表

1. **首页/问题输入页**: 输入待解决问题，选择思考流程
2. **冲突图构建页**: 交互式冲突图编辑器
3. **现状图构建页**: 不良效应收集与因果连接
4. **双赢方案页**: 方案生成与评估工具
5. **方案完善页**: 负面分支识别与修正
6. **实施计划页**: 四象限分析与行动清单
7. **成果展示页**: 完整思考流程回顾

### 3.2 页面流程

```
首页 → 冲突图 → 现状图 → 双赢方案 → 方案完善 → 实施计划 → 成果展示
```

## 4. 设计风格

### 4.1 视觉定位
- **风格**: 极简主义 + 思维导图美学
- **氛围**: 专业、清晰、专注
- **隐喻**: 大脑思维具象化，连线如神经网络

### 4.2 色彩系统

| 用途 | 颜色 | 说明 |
|------|------|------|
| 主色 | #2563EB | 信任蓝，引导交互元素 |
| 强调色 | #F59E0B | 冲突/问题标记 |
| 正向色 | #10B981 | 解决方案/成功 |
| 负向色 | #EF4444 | 不良效应/障碍 |
| 背景色 | #0F172A | 深色背景，聚焦思维 |
| 文字色 | #F8FAFC | 清晰可读 |

### 4.3 字体选择
- 标题: **Noto Sans SC** (中文无衬线，清晰现代)
- 正文: **Noto Sans SC** Regular
- 数据/代码: **JetBrains Mono**

### 4.4 动效设计
- 步骤切换: 滑动过渡 + 淡入淡出
- 图表连线: 描边动画(Stroke-dashoffset)
- 节点悬停: 微妙发光 + 缩放
- 页面加载: 渐进式元素揭示

## 6. 用户体验细节

### 6.1 引导机制
- 每个步骤显示当前进度指示器
- 提供示例输入，帮助用户理解
- 必填项验证，防止跳过关键思考

### 6.2 数据持久化
- 自动保存当前思考进度到localStorage
- 支持会话中断恢复
- 导出完整思考报告

### 6.3 响应式设计
- 桌面优先设计
- 平板/移动端适配
- 触摸操作优化
