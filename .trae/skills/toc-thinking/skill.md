# TOC清晰思考技能

## 技能描述

基于TOC（制约理论）的五步思考流程，通过引导式对话帮助用户将复杂问题可视化、系统化地找到双赢解决方案。适用于工作、生活、学习中的任何长期未解难题。

## 技能名称

**TOC清晰思考技能**

## 核心流程

```
困境定义 → 冲突图构建 → 现状图溯源 → 双赢方案破解 → 消除顾虑 → 说服实施
```

## 五步引导

### 第一步：定义困境（定义）

**目标**：理解用户面临的核心问题

**引导问题**：
- 发生了什么情况？
- 谁受到了影响？
- 这个问题持续了多久？
- 已经尝试过什么方法？

**输出**：清晰的问题陈述

---

### 第二步：冲突图构建（溯源）

**目标**：将问题转化为"两难冲突"，明确对立行为与背后的共同目标

**引导问题**：
- 你当前采取了什么行动？（D）
- 与之相反的行为是什么？（D'）
- D满足了什么需求？（B）
- D'满足了什么需求？（C）
- 两者的共同目标是什么？（A）

**输出**：完整冲突图

---

### 第三步：现状图溯源（破解）

**目标**：找出造成冲突和不良效应的根本原因

**引导问题**：
- 这个问题导致了哪些不良效应？
- 这些效应之间有什么关联？
- 什么是最根本的原因？

**输出**：现状图与核心问题

---

### 第四步：双赢方案（破解）

**目标**：推翻冲突图中的无效假设，开发双赢方案

**方法**：
1. **改变++**：挑战D→C假设，寻找例外
2. **不改变++**：挑战D'→B假设，优化现有行为
3. **条件改变**：找出冲突条件，分情况行动
4. **另一种改变**：跳出D/D'，直接满足B和C

**引导问题**：
- 真的是这样吗？（挑战假设）
- 总是真的吗？有没有例外？
- 有没有第三条路？

**输出**：1-4个候选激发方案

---

### 第五步：消除顾虑（消除顾虑）

**目标**：确保激发方案充分、无副作用

**引导问题**：
- 这个方案可能带来什么顾虑？
- 这些顾虑成立的前提是什么？
- 如何消除或缓解这些顾虑？

**输出**：完整可行的解决方案蓝图

---

### 第六步：说服实施（行动）

**目标**：克服执行障碍，促使相关方采取行动

**四象限分析**：
- **金子**：改变的好处
- **鳄鱼**：改变的坏处
- **美人鱼**：不改变的好处
- **拐杖**：不改变的坏处

**引导问题**：
- 如何先建立动力？
- 如何消除阻力？
- 第一步应该做什么？

**输出**：行动清单与承诺

## 技能原则

1. **可视化**：将隐性思维显性化
2. **先假言后验证**：挑战每个假设
3. **不妥协**：永远寻找双赢
4. **一次只做一件事**：聚焦最大价值

## 使用示例

```
用户：团队业绩下滑，不知道该加强管理还是给团队自主权

技能：
1. 理解困境：团队业绩问题，涉及管理力度决策
2. 构建冲突图：
   - D=加强管理控制
   - D'=给予团队自主权
   - B=规范可控
   - C=激发创造力
   - A=提升业绩
3. 溯源分析：找到根本原因是缺乏明确的目标聚焦机制
4. 双赢方案：引入OKR目标管理+适度授权
5. 消除顾虑：建立定期复盘机制、明确权责边界
6. 行动计划：两周内选定试点团队，制定首个目标
```
